# Publicações de demonstração

Criadas em 11/11/2026 para avaliar o layout do portal. Os textos e as programações são fictícios, com aviso no corpo de cada publicação. As fotos são ilustrativas e ficam armazenadas localmente.

Foram acrescentadas dez notícias e dez publicações na categoria Eventos. Os registros preexistentes foram preservados. As duas manchetes de demonstração estão marcadas como destaque. Cada publicação contém duas imagens; as duas manchetes contêm três.

As publicações podem ser editadas ou excluídas pelo painel administrativo. Os slugs `demo-noticia-01` a `demo-noticia-10` e `demo-evento-01` a `demo-evento-10` identificam este conjunto.
